This is a working repository for Isabella Perry's first data chapter of her MSc thesis at UBC Okanagan supervised by Dr. Noonan in the Quantitative Ecology Lab. The folder "SCRIPTS" contains all R scripts used in this project for cleaning data, running models, and extracting results with a separate folder enclosed containing the scripts for generating figures. The folder "FIGURES" contains copies of figures used in poster presentations and the final data chapter. As this is a working repository, all code must be used with caution.
